# Full Python Architecture: NiceGUI Frontend + FastAPI Backend

A complete, production-grade Python full-stack application featuring **FastAPI** as the backend engine and **NiceGUI** as the reactive Python web frontend.

---

## 🚀 Quickstart Guide

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Start the FastAPI Backend
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 3000 --reload
```
API Documentation and interactive Swagger UI will be live at:
**http://localhost:3000/docs**

### 3. Start the NiceGUI Python Frontend
In a separate terminal:
```bash
python frontend/app.py
```
Open your browser at:
**http://localhost:8080**
